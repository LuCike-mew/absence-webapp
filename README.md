# absence-webapp# MiraiBot WebApp — клиентская часть (Telegram Mini App)

Фронтенд для Telegram-бота **MiraiBot** (бэкенд-репозиторий: [absence_bot](https://github.com/LuCike-mew/absence-tg-bot)), реализованный в виде **Telegram Mini App** и развёрнутый на **GitHub Pages**.

Предназначен для студентов колледжа (например, группы ВЕБ-42): позволяет прямо в Telegram удобно выбирать пары, на которых планируется пропуск, просматривать актуальное расписание с учётом замен и отправлять данные обратно в бот.

## Как это устроено

Поскольку приложение работает на **GitHub Pages** (статический хостинг без своего сервера и базы данных), вся коммуникация с ботом построена на передаче данных через **URL-параметры** и стандартный SDK Telegram:

```text
MiraiBot (Python) ──► gzip + base64 ──► URL (?data=...) ──► index.html (GitHub Pages)
                                                                     │
MiraiBot (SQLite) ◄── Telegram.WebApp.sendData() ◄─── выбор студента ┘
```

1. **Бэкенд** парсит актуальное расписание, замены и достаёт историю пропусков пользователя.
2. Данные сжимаются с помощью **gzip** и кодируются в строку **base64**.
3. Ссылка передаётся во фронтенд через параметры запроса (`?data=...`).
4. **Mini App** распаковывает данные прямо в браузере, отрисовывает интерактивный интерфейс и возвращает выбор студента обратно в чат через `Telegram.WebApp.sendData()`.

## Структура проекта

Репозиторий максимально минималистичен и содержит всего один рабочий файл:

```text
absence-webapp/
├── index.html       # Весь интерфейс, логика распаковки gzip/base64 и интеграция с Telegram SDK
└── README.md
```

## Особенности

- 🚀 **Полная автономность** — работает как статическая страница, не требует отдельного сервера или БД для хостинга фронтенда.
- 📦 **Zero-dependency / Single-file** — весь код (HTML, CSS, JS) собран в одном компактном файле `index.html` для мгновенной загрузки в Telegram.
- 🎨 **Адаптивность под Telegram** — использует переменные тем оформления `Telegram.WebApp.themeParams`, автоматически подстраиваясь под светлую или тёмную тему клиента.

## Деплой и настройка

1. Приложение автоматически публикуется на **GitHub Pages** из ветки `main` (корневая папка `/`).
2. Итоговая ссылка вида `https://lucike-mew.github.io/absence-webapp/` указывается в конфигурации бэкенда (`config.py` / `.env`) для генерации кнопки запуска Mini App.
